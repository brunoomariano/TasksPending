# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Do not disclose vulnerabilities in a public issue. Once this repository is public, use GitHub's private vulnerability reporting for this repository and include the affected version, a minimal reproduction and any suggested mitigation.

Before making the repository public, the maintainer must enable private vulnerability reporting in the repository security settings. Until then, reports should stay within the existing private collaboration channel.
